# Caddy Reverse Bin v0.3.3

## Highlights

- Security release: fixes remotely triggerable HTTP/2 denial-of-service bugs in `golang.org/x/net` reachable from the Caddy listener and the reverse proxy (GO-2026-6603, GO-2026-6610, GO-2026-6611, GO-2026-6612, GO-2026-6617).
- Caddy is updated to v2.11.7 and all Go dependencies are at their latest versions.

## Breaking changes

Building the plugin now requires Go 1.26 or newer, because Caddy v2.11.7 requires it. Existing Caddyfiles and backend executables remain compatible.

## Full list of changes

- Update Caddy from v2.11.4 to v2.11.7, CertMagic from v0.25.3 to v0.25.6, and `golang.org/x/net` from v0.55.0 to v0.61.0.
- Update gRPC, `golang.org/x/text`, `golang.org/x/crypto` and the OpenTelemetry exporters past their published advisories.
- Update the Go module version to 1.26.10.
- Replace Dependabot with govulncheck and a CI gate that requires the latest dependency versions; tag releases run both before publishing.
- Document how detector args key backend processes.
- Bind the example's port 9080 to loopback.
