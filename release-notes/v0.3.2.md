# Caddy Reverse Bin v0.3.2

## Highlights

- Managed Unix socket backends now create their socket directories before launch and clean up stale socket files safely across startup and shutdown.
- Caddy and security-sensitive transitive dependencies have been updated.

## Breaking changes

None. Existing Caddyfiles and backend executables remain compatible.

## Full list of changes

- Create managed static-app Unix socket directories with owner-only permissions before launching a backend.
- Remove pre-existing socket files before launch and clean up socket files only after the backend process exits.
- Prevent a replacement backend from starting while a previous process has not stopped successfully.
- Update Caddy from v2.11.2 to v2.11.4, CertMagic from v0.25.2 to v0.25.3, and related Go dependencies with security fixes.
- Update the Go module version to 1.25.1 and Zap to v1.28.0.
