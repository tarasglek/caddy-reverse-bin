# Caddy Reverse Bin v0.4.0

Lifecycle rewrite.

- `reverse-bin` is a `reverse_proxy` upstream source: `reverse_proxy { dynamic reverse-bin { … } lb_retries 1 }`. Handler directive gone; subdirectives keep their names.
- Removed: `pass_env`, `pass_all_env` (env is the whole environment: `env PATH={env.PATH}`), `termination_grace_ms` (fixed 10s), `termination_kill_wait_ms`.
- `health_check` optional: ready on any response, or on `STATUS` (also `2xx`).
- One running copy per `dir` and `reverse_proxy_to`, across reloads.
- Retries recheck the app; failed starts not repeated.
- Braces in `reverse_proxy_to` refused (Caddy expands them).
- Detector output: one JSON value, at most 1 MiB.
- `detectorschema`, schema, examples removed.
